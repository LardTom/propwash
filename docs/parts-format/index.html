#Files and loadingDateien und Laden

  • Categories are the folder names: frame, stack, motor, prop, video, battery, accessory, chemistry. Sub-folders and other folder names are errors.Kategorien sind die Ordnernamen: frame, stack, motor, prop, video, battery, accessory, chemistry. Unterordner und andere Ordnernamen sind Fehler.
  • The id is <namespace>:<file name without .json>; the path may only contain [a-z0-9_.-] and must be unique across all categories.Die Id ist <namensraum>:<dateiname ohne .json>; der Pfad darf nur [a-z0-9_.-] enthalten und muss über alle Kategorien eindeutig sein.
  • Files are loaded only by PropwashApi.parts().loadBundled(modId) from the add-on’s own jar, in the order chemistry → frame → stack → motor → prop → video → battery → accessory, alphabetically within a folder. Not from world data packs, no /reload.Geladen werden die Dateien nur von PropwashApi.parts().loadBundled(modId) aus dem eigenen Jar des Add-ons, in der Reihenfolge chemistry → frame → stack → motor → prop → video → battery → accessory, innerhalb eines Ordners alphabetisch. Nicht aus Welt-Datenpaketen, kein /reload.
  • Propwash’s own 36 built-in parts and chemistries are files in exactly this format.Propwashs eigene 36 eingebaute Teile und Zellchemien sind Dateien in genau diesem Format.

#ConventionsKonventionen

  • Ids without a namespace ("m22", "lipo") mean propwash:…. Always write other namespaces in full.Ids ohne Namensraum ("m22", "lipo") meinen propwash:…. Andere Namensräume immer voll schreiben.
  • Numbers are JSON numbers; integers must not have decimals ("kv": 1750, not 1750.5).Zahlen sind JSON-Zahlen; ganze Zahlen dürfen keine Nachkommastellen haben ("kv": 1750, nicht 1750.5).
  • [min, max] ranges may also be a single number for cells ("cells": 6 = [6, 6]).[min, max]-Bereiche dürfen bei cells auch eine einzelne Zahl sein ("cells": 6 = [6, 6]).
  • Positions are [x, y, z] in millimetres: origin in the middle of the frame at the height of the stack plate, +X right, +Y up, −Z forward.Positionen sind [x, y, z] in Millimetern: Ursprung in der Rahmenmitte auf Höhe der Stack-Auflage, +X rechts, +Y oben, −Z vorn.
  • "format": 1 is optional. New optional fields can come with minor API versions; the format number only rises for incompatible changes."format": 1 ist optional. Neue optionale Felder können mit Nebenversionen der API kommen; die Formatnummer steigt nur bei inkompatiblen Änderungen.

#Errors and warningsFehler und Warnungen

  • Propwash first reads all files. If any has an error, loadBundled throws one exception listing every error as file – field: message and registers nothing.Propwash liest zuerst alle Dateien. Hat eine einen Fehler, wirft loadBundled eine Ausnahme mit jedem Fehler als Datei – Feld: Meldung und meldet nichts an.
  • Unknown fields are not errors: they are logged as a warning and ignored, so a file written for a newer Propwash still loads.Unbekannte Felder sind keine Fehler: Sie landen als Warnung im Log und werden ignoriert, damit eine Datei für ein neueres Propwash trotzdem lädt.
  • PropwashEvents.PART_REGISTERED fires for every part (not for chemistries).PropwashEvents.PART_REGISTERED feuert für jedes Teil (nicht für Zellchemien).

Check a file without starting the game: PropwashApi.parts().fromJson(kind, id, json) throws an IllegalArgumentException naming the field. The online configurator reads Just More Parts in this format too.

Eine Datei ohne Spielstart prüfen: PropwashApi.parts().fromJson(kind, id, json) wirft eine IllegalArgumentException, die das Feld nennt. Der Online-Konfigurator liest Just More Parts ebenfalls in diesem Format.
