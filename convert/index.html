Convert old share codesAlte Sharecodes umrechnen

Since Propwash 0.6.0, share codes start with PW3-. Paste your old code here – or a whole Discord post: every PW1-…, PW2… and PWD1-… code in it becomes PW3 in place, links included.

Seit Propwash 0.6.0 beginnen Sharecodes mit PW3-. Füg hier deinen alten Code ein – oder einen ganzen Discord-Beitrag: Jeder PW1-…-, PW2…- und PWD1-…-Code darin wird an Ort und Stelle zu PW3, auch in Links.

The conversion runs in your browser. Nothing you paste is uploaded or stored.Die Umrechnung läuft in deinem Browser. Nichts, was du einfügst, wird hochgeladen oder gespeichert.

    About the conversionZur Umrechnung

    The converter works like /propwash code convert in the game: an old code becomes exactly the PW3 code the game writes, with the frozen parts tables of Propwash and Just More Parts. PW3 codes are only checked. A code that a person put together by hand can name parts no version knows; it can’t be converted. Open a code in the configurator to see the drone, its flight figures and its paint.

    Der Umrechner arbeitet wie /propwash code convert im Spiel: Ein alter Code wird genau zu dem PW3-Code, den das Spiel schreibt, mit den eingefrorenen Teile-Tabellen von Propwash und Just More Parts. PW3-Codes werden nur geprüft. Ein von Hand gebauter Code kann Teile nennen, die keine Version kennt; er lässt sich nicht umrechnen. Öffne einen Code im Konfigurator, um die Drohne, ihre Flugwerte und ihren Lack zu sehen.

    PWD1-… codes come from the drone editor of Propwash 0.5 and hold only the values of a creative drone. As in the game, such a code becomes the freestyle drone of the Flight School with the Creative Flight Controller and all its creative values, now as a PW3 code. In creative mode the game creates the drone with every value; in survival only the build counts.

    PWD1-…-Codes stammen aus dem Drohnen-Editor von Propwash 0.5 und enthalten nur die Werte einer Kreativ-Drohne. Wie im Spiel wird so ein Code zur Freestyle-Drohne der Flugschule mit dem Kreativ-Flugcontroller und allen Kreativ-Werten, jetzt als PW3-Code. Im Kreativmodus erzeugt das Spiel die Drohne mit allen Werten; im Überleben gilt nur der Bauplan.
